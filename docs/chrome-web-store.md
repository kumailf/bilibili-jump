# Chrome 网上应用店上架说明（比利空降助手）

测试通过后按下列清单提交。

## 包

```bash
npm run pack
```

上传 `release/bilibili-jump-chrome.zip`（或开发者控制台要求的 zip 根目录含 `manifest.json`）。

## 商店文案建议

**名称：** 比利空降助手  

**简短说明（≤132 字）：**  
自动识别 B 站长视频片尾版权规避填充，并在进度条标记、自动跳过。仅本机分析，不上传视频。

**详细说明：**  
看长视频时，片尾常被插入大段无关风光/循环画面以规避版权。本扩展在本地用画面特征识别这类片段：  
• 启用后自动工作  
• 识别成功后在进度条用颜色标出跳过段（类似空降助手）  
• 播放到该段时自动跳过  
• 不确定时保持静默，不弹窗打扰  

权限说明：仅访问 bilibili.com 播放页与本地 storage（保存开关与跳过时间点）。

## 隐私权政策（可放 GitHub Pages / 仓库）

本扩展：  
1. 不收集个人身份信息；  
2. 不向开发者服务器发送视频内容或观看记录；  
3. 跳过时间点仅存于用户浏览器 `chrome.storage.local`；  
4. 用户卸载扩展即可清除本地数据。
