# Chrome 网上应用店上架说明（比利空降助手）

当前打包版本：**1.3.3**。已上架则必须升版本号后再传 zip；首次提交可用该号。

## 包

```bash
npm run pack
```

上传 `release/bilibili-jump-chrome.zip`（zip 根目录含 `manifest.json`）。

开发者控制台：https://chrome.google.com/webstore/devconsole

**更新已有条目：** 选中「比利空降助手」→ 构建（Package）→ 上传新 zip → 填「此版本的新功能」→ 提交审核。

**此版本的新功能（可贴控制台）：**  
修复长视频已识别却看不到进度条、检测被中途打断的问题；画面确认后即可标记并可跳过，声音交叉确认后写入缓存。适用于约 16 分钟以上长视频。

## 商店文案建议

**名称：** 比利空降助手  

**简短说明（≤132 字）：**  
自动识别并跳过 B 站长视频片尾无意义片段，进度条标记可跳区间。仅本机分析，不上传视频。

**详细说明：**  
看长视频时，片尾常有大段无关风光、循环画面等无意义内容。本扩展在本地用画面与声音识别这类片段：  
• 启用后自动工作（建议片长约 16 分钟以上）  
• 识别到后在进度条标出青色可跳段  
• 播到该段时可自动跳过；交叉确认后记住下次直接跳  
• 播放中不打断进度  
• 不适用时保持静默  

权限说明：仅访问 bilibili.com 播放页与本地 storage。

## 隐私权政策（可放 GitHub Pages / 仓库）

本扩展：  
1. 不收集个人身份信息；  
2. 不向开发者服务器发送视频内容或观看记录；  
3. 跳过时间点仅存于用户浏览器 `chrome.storage.local`；  
4. 用户卸载扩展即可清除本地数据。
