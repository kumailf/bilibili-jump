# 比利空降助手 · 隐私权政策

**生效日期：** 2026-09-08  
**产品：** 比利空降助手（Chrome 扩展）  
**代码仓库：** https://github.com/kumailf/bilibili-jump

## 我们收集哪些数据

本扩展**不收集、不上传、不出售**可识别个人身份的信息。

仅在您本机浏览器中通过 `chrome.storage` 保存：

1. **启用开关**（是否开启自动跳过）  
2. **已确认跳过段的起点与终点时间**（按视频标识缓存，便于再次打开时直接标记进度条）

这些数据只存在于您的设备本地扩展存储中，**不会**发送到开发者服务器。

## 网络请求

为在 B 站播放页工作，扩展可能请求：

- `www.bilibili.com`：在视频页注入并运行跳过逻辑  
- `api.bilibili.com`：查询分 P 与预览图元数据  
- `*.hdslb.com`：下载进度条预览雪碧图，**仅在本机**做画面分析  

请求目的仅为完成本地识别与跳过，**不包含**账号密码、支付信息，也不把视频内容回传给开发者。

## 远程代码

本扩展**不使用远程代码**：不会从互联网下载并执行脚本。分析逻辑均打包在扩展包内，在本机运行。

## 权限说明

| 权限 / 主机权限 | 用途 |
|-----------------|------|
| `storage` | 保存开关与跳过时间点 |
| bilibili / api / hdslb | 播放页运行与本地预览图分析 |

## 数据保留与删除

跳过段缓存保存在本机，数量有上限。您可以随时：

- 在扩展弹窗中关闭「启用」  
- 在 Chrome「扩展程序」中清除该扩展的网站数据 / 卸载扩展，本地数据随之清除  

## 儿童隐私

本扩展不面向 13 岁以下儿童，也不故意收集儿童个人信息。

## 政策更新

若本政策变更，将更新本页面并调整「生效日期」。继续使用扩展即表示您了解更新后的说明。
